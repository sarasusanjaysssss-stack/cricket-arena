
# 🏏 CRICKET ARENA

A complete cricket team management and live scoring application.

## Features

1. Player Registration and Login
2. Team Creation
3. Join-Team Requests
4. Captain Approval
5. Team Chat and Private Chat
6. Live Cricket Scoring
7. Complete Batting Scorecard
8. Complete Bowling Scorecard
9. Match Results and Statistics

## Technology
- Flutter
- Firebase
- Android
